# Retired

Things taken out of the app but kept here for reference. Nothing in this folder is built, shipped or read by the app.

- `Package.appxmanifest` and `Assets/`: the packaged (MSIX) manifest and logo images. Aether has been unpackaged since ADR-0017, so only `AppIcon.ico` is used.
- `removed-strings.txt`: language-file entries that nothing used any more.
- `removed-tokens.txt`: design tokens and styles that nothing used any more.
