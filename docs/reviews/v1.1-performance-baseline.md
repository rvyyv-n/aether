# Aether v1.1.0 Performance Baseline

Captured on **2026-11-25** against `master` (`702e0e4`, pre-Pass 20 / pre-Pass 21) using `tools/measure-performance.ps1` and a synthetic 1080p60 H.264/AAC clip (`bench-1080p60.mp4`).

## Machine

- **GPU:** AMD Radeon R7 350 Series
- **Display:** 1920 × 1080 @ 180 Hz
- **.NET SDK:** 10.0.100
- **Build tested:** `src\Aether.App\bin\x64\Release\net10.0-windows10.0.26100.0\win-x64\Aether.App.exe` (Release x64, non-AOT)

- Key gap observed: ~95 ms before `Main` (CoreCLR startup) + **~533 ms** between `Main` and first rendered frame (eager XAML loading of 1,634-line `MainPage.xaml`, `SettingsControls.xaml` merged at app startup, and startup file waits).

- **Dropped by video output:** 0
- **Dropped by decoder:** 0

- **Garbage collections:** 1 Gen0, 1 Gen1, 1 Gen2; **7.7 ms** total GC pause

## v1.1.0 Targets (Pass 21)

- **Cold start (Native AOT warm median):** `< 250 ms`
- **Playback dropped frames (1080p60 / 1080p120 / 4K with blur active):** `0`
- **GPU hot path:** Direct-to-backbuffer render when no blurred card is visible; live D3D11 GPU frame-time ms in Diagnostics (`Ctrl+I`).
- **Working-set RAM & GC:** Reduced via `x:Load` visual-tree deferral, lazy `SettingsControls.xaml`, and Native AOT.
