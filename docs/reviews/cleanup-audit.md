# Aether Codebase Cleanup Audit

**Audit Date:** October 14, 2026  
**Scope:** `C:\Users\rayyan\.t3\worktrees\aether\pass-7-menus-toasts-diagnostics`  
**Focus:** Unused types, members, NuGet packages, resources, assets, leftover debug output, stale documentation/roadmap references, and `.gitignore` coverage.

---

## Executive Summary

The Aether codebase is remarkably disciplined:
- **Zero TODO / FIXME / HACK / XXX markers** exist across the entire source and test tree.
- **Zero debug logging statements** (`Debug.WriteLine`, `Console.WriteLine`, `Trace.WriteLine`) leak into production player or UI assemblies.
- **Zero 0-byte or placeholder files** exist on disk.
- **Strict test suites actively enforce naming and lookups**, such as checking that every string queried via `AppStrings.Get`/`Format` exists in `Resources.resw`, and that all legacy XAML alias tokens and color/brush pairs exist.

However, several iterations of refactoring (most notably the migration from packaged MSIX to unpackaged WinUI 3 in ADR-0017, the split of In/Out and settings navigation items, and the renumbering of roadmap passes) left behind dead code, unused duplicate resource strings, packaged assets no longer deployed, and orphaned members.

Key findings include:
1. **Unused NuGet Package & Project Reference:** `Microsoft.Windows.SDK.BuildTools.WinApp` remains in `Aether.App.csproj` despite the app being unpackaged (where winapp CLI package identity is unused). Additionally, `Aether.App.csproj` references `Aether.Server.LanHost.csproj` even though no code in `Aether.App` currently consumes it (LAN streaming is Pass 11).
2. **Packaged MSIX Assets & Manifest:** Eight packaged logo images (`SplashScreen.scale-200.png`, `Square150x150Logo.scale-200.png`, etc.) and `Package.appxmanifest` remain in `src/Aether.App/Assets/`, copied to build outputs on every build, even though unpackaged desktop execution only uses `AppIcon.ico`.
3. **Dead Constants & Orphaned Members:** Unused constants include `ZoomStep` (hardcoded in XAML slider), `SingleInstance.Infinite`, and `Kernel32.INFINITE`. `QrPairingService` in `Aether.Server.LanHost` has zero references across both `src` and `tests`.
4. **Dropped Feature Leftovers:** Roadmap Task 5.1 (`OverlayHud` tick calculation) was explicitly marked "Dropped (not needed, per the user)", but `TickCalculator.cs` and `TickCalculatorTests.cs` remain in the repository.
5. **Unused / Duplicate Resource Keys (54 keys in `Resources.resw`):** 16 keys are dead duplicates or superseded strings (`Settings_Nav*` superseded by `Settings_Page_*`, `Settings_CustomMpvOptions_*` superseded by `Settings_CustomOptions_*`, `Settings_RestartNotice` superseded by split controls, etc.); 6 are unused UI strings (`TitleBar_*`, `EmptyState_Hint`, `Common_*`); and 32 are forward-looking strings for future passes (Pass 8 PiP, Pass 7.21 Rail, and Pass 9 Link Playback) which are safe to retain.
6. **Unused XAML Tokens & Styles (`DesignTokens.xaml`):** 3 unused styles (`AetherOsdPanelStyle`, `AetherSettingsRowStyle`, `AetherBadgeStyle`), 4 unused motion duration doubles, and several layout/typography doubles are never referenced in XAML or code. Note that 23 legacy alias keys and all color keys are actively required by `DesignTokensTests` and must not be deleted.
7. **`.gitignore` Architecture Gap:** Native library ignore rules only match `src/Aether.App/Native/x64/`, leaving `arm64` and `x86` native drop locations unignored despite active publish profiles for both.
8. **Stale Documentation & Roadmap Numbering:** `ROADMAP.md` tasks 7.19 and 7.20 refer to "the menu entries in 9.1" and "Wire the 9.1 menu items" (referring to screen 9.1 from the mockup deck, which easily confuses readers now that Pass 9 is Link Playback). `README.md` lists the `S` shortcut and LAN streaming as active features even though LAN streaming is disabled until Pass 11.
