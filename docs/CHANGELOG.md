# Changelog

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]
### Added
- A way to measure speed on your own PC: `tools\measure-performance.ps1` opens Aether a few times and reports how long the window takes to appear, and with `-Video` plays a clip and reports dropped frames and memory clean-up pauses. Aether only records these timings when the script asks it to.
- Watch on your phone: press `S` or pick Stream in the right-click menu to open a card with a QR code and address. Streaming is off until you switch it on, shows how many phones are watching, and stops when you switch it off, close the file or quit.
- Aether can update itself. Settings › About has Check now, which looks at the project's GitHub releases, downloads a newer version in the background and installs it when you close Aether (or at once with Restart to update). Check for updates automatically is on by default (switch it off in Settings › About) and looks once a day, a short while after launch. Copies run from a zip do not update themselves. A tag push builds the installer, the zip and the update packages into a draft release.
- yt-dlp now comes with Aether, so the first web link plays with no setup. If it is ever missing, Install on the link-failure screen or the Streaming page downloads it with a progress count, checks the download against the release's published checksum, and starts using it at once. Aether runs the newest of its downloaded copy, the bundled copy and one on PATH, checks once a day for a newer one (switch off with Update automatically), and uninstalling removes the downloaded copy.
### Changed
- The download is now a normal Windows setup (`AetherPlayer-win-Setup.exe`) with a small window instead of the old installer that opened a terminal window. It installs for your account without admin rights, adds Start menu and desktop shortcuts, appears in Settings › Installed apps and, unlike the old installer, takes updates. The old installer and the `Install.cmd` in the portable zip are gone; the portable zip just runs. Copies installed with the old installer are moved over the first time the new setup runs.
- Updates now include releases marked as pre-release on GitHub, so beta testers move from one beta to the next.
- The phone streaming card warns when Windows lists the network as public (café or hotel Wi-Fi), since others on it could watch too. Streaming still works there.
- The yt-dlp button on the Streaming page says "Installing…" during a first install instead of "Updating…", and keyboard focus comes back to it (or to the switch below once it disappears) when the install or update finishes.
- The phone streaming card works better with the keyboard and screen readers: focus always lands inside the card (on the status line when streaming can't be switched on, so the reason is read out), and Narrator announces when streaming starts, fails or a phone joins.
- Settings › About no longer gets stuck on "Downloading" after an update has finished downloading, which also left Check now doing nothing until Aether was restarted.
- Shorter pauses for memory clean-up while a video plays: the low-pause settings the design always called for are now really switched on, so a clean-up runs alongside playback instead of stopping it.
- The window's edge line: over a playing video it is now black in both themes (dark theme showed a pale line along the top), and Settings and the home screen get the normal Windows border back instead of a black frame around the whole window in light theme.
- Subtitles no longer sit behind the transport bar: while the bar shows they are lifted just above it (following the bar as it grows and shrinks) and ease back down when it hides, in windowed and full screen. The Position setting still applies on top, and Top is never lifted. Only the part of the bar over the picture counts, so a letterboxed video keeps its subtitles where they were. A `sub-margin-y` in the custom mpv options turns the lift off.
- The Small subtitle size is about a quarter smaller (30 instead of 40 on mpv's 720-high scale), so it no longer looks nearly as big as Medium on the video. Medium, Large and Extra large are unchanged, and the Settings preview follows the same sizes.
- Subtitles now use a font mpv can really draw: the default Segoe UI Variable was silently replaced by Arial on the video, so it is now sent as Segoe UI. Fonts that are only installed as variable fonts (for example Bricolage Grotesque) still cannot be drawn on the video by the bundled mpv and fall back to Arial.
- The subtitle font list in Settings now shows the installed fonts. It used to read every name as "en-us" because of a mistake in how font names were read from Windows, so the list was effectively empty.
- Timecodes are a little larger (14 instead of 13) and keep their even-width digits, so the clock and seek bubble read more easily and do not shift as they tick. The title bar file name keeps its 320 wide limit, now set by a shared size, and a few stray font settings moved onto the shared ones. The font itself stays Segoe UI Variable.
- First-run tour: the cards now stay fully inside the window (the second one no longer hides Next), Skip tour is no longer clipped, the side rail is left out of the tour and stays shut while it runs, the keys card sits beside the home content instead of over the file list, the first card mentions web links, and the lit ring pulses gently while a progress bar fills as you go (both off when Windows animations are off).
- Settings › General now holds the window settings (remember window size, always on top) next to battery saver and history, instead of leaving them on the Playback page.

### Added
- Settings in full screen: no new control was needed. With the title bar and gear hidden, `Ctrl+,` (changeable on the Shortcuts page), the ⋯ menu on the bottom bar and the Settings item in the side rail all open Settings, which leaves full screen first so the back arrow is there.
- Include Look in the clip drawer: with Precise on, a new switch bakes the Look from the Video panel (grade, sharpen, grain, denoise) and its colour sliders into the saved clip, so the clip looks like what you see. It is on by default and remembered; Fast cuts can't change the picture, so the switch is greyed there. If nothing is set, the hint says the clip will look like the original. Zoom, rotation and aspect ratio are not included. A look file with an apostrophe in its name now also loads correctly.
- Denoise in the Look section of the Video panel: Off, Light, Medium or Strong, remembered between sessions and off by default. It uses more power, so it suits machines with a dedicated graphics card; Diagnostics shows the dropped frames while you try it.
- Look in the Video panel: below the colour sliders, pick a Grade (Warm, Cool, Vivid, Teal and orange, Faded film, Black and white, or your own `.cube` looks added with Add a look…), and add Sharpen and Grain with sliders; Reset look clears them. Changes show live, are remembered for the next file and the next session, and everything is off by default so normal playback is unchanged. While a Look is on, hardware decoding hands frames back to the processor, which is slower: check Diagnostics (dropped frames) on your machine.
- Fast clip export now shows where the cut will really start: a faint band and tick on the seek bar run from the keyframe the cut begins on up to your In point, and the hint says how early it starts (for example "This one starts 1.4 s early"). It only looks at a short stretch before In, never the whole file, and shows nothing for web links, Precise mode or when no keyframe is found.
- Clip drawer export options: the open drawer now starts with a Cut control (Fast or Precise) and a size limit (No limit, 10, 25, 50 MB or Custom, 1 to 4000 MB). A hint line explains the choice, and if the limit is too small for the clip it says the smallest possible size and Export clip is disabled until you change the range or limit. Both choices are remembered. While a clip saves, its row shows percent and time left with a Cancel button that removes it quietly; a finished Precise clip shows which encoder made it (NVIDIA, Intel, AMD or CPU). Fast export works as before.
- Precise clip export (engine only, drawer controls come next): re-encodes the marked clip so it starts and ends on the exact frame. Uses the graphics card encoder when one works (NVIDIA, Intel, then AMD) and falls back to software x264, including mid-export if a card encoder fails. An optional size limit picks the video quality to fit, with a clear message if the limit is too small. Reports progress, speed and time left; cancelling or failing deletes the partial file. Fast (stream copy) export is unchanged.
- Precise clip export is sturdier: a bad clip or full disk no longer switches off the graphics card encoder for the session, a size limit is checked on the finished file and retried once if it came out too big, two exports in the same second can't share a file, a failing progress display can't hang an export, and cancelling is cleaner.
- Picture in picture: `P` or the right-click menu floats the video in a small always-on-top window (400×225 and up) with Back to full window on hover; the video engine keeps playing without a restart, and the window remembers where it was.
- First-run tour: on the first launch Aether lights up its real controls one at a time (opening a video, the bar, the side rail, the right-click menu, the keys and the gear) with a short note beside each; skip it at any time, or see it again from Settings › About.
- Settings › About ends on an "Aether" row that opens to show the version, a note that everything stays on this device, and a GitHub link; it sits in the same list as the other rows and starts closed.
- Saved links in the right-click Recent menu can now be played, the same as from the home screen; Stream stays greyed out until Pass 11.
- Seek modifiers: `Shift+←/→` skips 1 second and `Ctrl+←/→` skips 30 seconds (plain arrows stay 5 seconds); all four keys are changeable on the Shortcuts page.
- Clip export shortcut: `Ctrl+E` exports the marked clip (changeable on the Shortcuts page), and shows a toast when no In and Out are set.
- Link Playback (yt-dlp, Pass 9):
  - Stream resolution with yt-dlp: resolves YouTube and 1000+ streaming sites using `--dump-json`, passing extracted direct stream URLs and required HTTP headers directly to libmpv.
  - Stream failure handling & user recovery: classified errors (private video, sign-in required, region-blocked, live not started, offline, unsupported site, missing yt-dlp) with actionable recovery options: Retry, Edit link, Open in browser, and Cancel.
  - Process tree isolation: concurrent asynchronous stdout/stderr draining with clean `Kill(entireProcessTree: true)` on user cancellation or timeout.
  - Hero state indicators: loading spinner displaying domain name with a 10s "still working..." notice.
  - Home screen link paste: `Ctrl+V` on empty state immediately triggers link resolution and playback; updated subtitle hint to "Drop a file, paste a link or press Ctrl+O".
  - Recents integration: remote streams saved in recent history with extracted video titles, durations, and original URLs.
  - Remote stream clipping guard: lossless clip export displays neutral toast "Save the file first to export clips" while frame copy (`Ctrl+C`) and frame save (`Ctrl+Shift+S`) continue working via mpv screenshot.
  - Engine restart carry-over: preserves `OriginalWebLink` across engine re-initialization and settings changes.
  - Quality picker: a button on the pill (links only) lists Auto, each size the video offers and Audio only; your pick is remembered for future links and switches the video in place at the same moment.
  - Skip button: with chapter auto-skip off, a discreet "Skip Sponsor" button shows for the first seconds of a matching chapter.
  - Resume: a "Resumed at 12:34" toast with Start over when a file or link picks up where you left it; links are remembered by page address, so the saved place survives expiring stream addresses.
  - YouTube subtitles: a link's own subtitle tracks (and automatic captions in your preferred language, labelled "(auto)") appear in the tracks flyout and use your caption font and size.
  - YouTube links now play with their sound (the separate audio stream is passed to the player).
  - Chapter marks: the seek bar shows small gaps where chapters start and the hover bubble names the chapter; `Page Down` / `Page Up` jump to the next / previous chapter (changeable on the Shortcuts page), for links and files with chapters.
  - Chapter auto-skip (off by default): Settings › Playback skips chapters whose names match a list (Sponsor, Intro, Outro to start), whole words only, once per video and never after you seek into one yourself, with a "Skipped … · Back" toast.
- Playback & high-refresh display pacing: bypassed forced display-fps-override on high-refresh displays (>60 Hz), restoring native presentation timing ("0") to prevent GPU 3D engine starvation under display-resample and spline36 on high-refresh displays (120/144/180 Hz).
- Playback performance: software decoding fallback under auto-safe now retains full frame readahead queue (fix R2); XAML layout updates and string allocations for clock and seek bar gated while controls are hidden (fix R3).
- UI finish: More (…) menu items now feature Segoe Fluent Icons (Back 1 frame, Forward 1 frame, Loop, Always on top); Springy and Quick motion profiles tuned for smooth, refined transitions.
- Housekeeping: the window title, About diagnostics lines, proxy hint and Diagnostics wording now come from the language file; unused language entries and design tokens, dead constants, the packaged-app manifest and logo images moved to `retired/`; native libraries for every architecture are ignored by git; the README no longer presents phone streaming as working before Pass 11.

- Aether runs as a standalone app without Developer Mode or certificates, with a per-user installer (`AetherInstaller.exe`, or `tools/Install.ps1`) and a portable build. The installer needs no admin rights, upgrades cleanly, asks before closing a running Aether, and adds Aether to Open with and to Installed apps.
- Player bar matches the design: a rounded see-through card with the video blurred behind it, the design's play, speed, skip and full-screen controls, and a title bar whose gear and Back match the window buttons.
- Diagnostics panel (Ctrl+I, changeable in Settings → Shortcuts): decoder, video, frame rate, display refresh, dropped frames and cache on a solid panel, with a Copy button.
- Aether now reads the refresh rate of the monitor the window is on (and follows it to another monitor or a changed display mode) and tells the player, so 120 fps clips no longer lose every other frame with Smooth motion on.
- Toast notifications: a small card above the controls (or near the bottom when they hide) with an optional dot and action and a Dismiss button. One shows at a time, failures go first, a toast with an action is never replaced, repeats show once, and the timer (4 s, or 8 s with an action) pauses while the pointer or keyboard focus is on it or a menu or dialog is open. Nothing shows them yet.
- Settings for VLC-style options: deinterlacing (with method), aspect ratio, snapshot folder, format and file name, network buffer size, HTTP proxy, RTSP transport, repair of damaged AVI files and skipping H.264 deblocking. Audio keeps pitch when you change speed, and surround sound can be mixed down to stereo. The screen stays awake while a file plays (switch off in Settings → Playback). The buffer size, AVI repair and deblocking apply after an engine restart; the rest apply straight away.
- Right-click menu on the player: Open file, Open URL, Recent files, Speed, Always on top, Diagnostics, Settings and Clips, with each shortcut shown as you have set it. Audio, Subtitles, Video, Copy frame, Save frame, Picture in picture and Stream appear greyed out until they are built.
- Ctrl+, opens Settings (changeable in Settings → Shortcuts). It was the one key the shortcut list used to refuse; only Ctrl with comma or full stop is now allowed, and the frame-step keys ignore Ctrl.
- Toasts now appear for a hardware decoder falling back to software (with a Settings button), a yt-dlp update succeeding or failing, and a saved or failed clip export (Show in folder opens the folder with the clip selected). They sit above the export chip or clip drawer when it shows.
- Video in the right-click menu now opens a panel above the controls with zoom (and Reset), rotate 0°/90°/180°/270°, aspect ratio and brightness, contrast, gamma and saturation sliders with Reset colours. The choices last for the open file and come back after an engine restart; a new file starts from Settings → Video again.
- Speed button: now a plain text button that sits like the icons beside it, and lights up when the speed is not 1×. The bar's times use the app's normal font instead of a typewriter one, with the total length muted.
- Title bar: the settings gear and Back now match the weight of minimise, maximise and close, and stay flush with them at any display scale.
- Title bar: the file name shows as plain muted text after "Aether" instead of a grey pill.
- Slim controls while a video plays: the bar shrinks to one row (Open, Play, the times around the seek bar, Mute and Full screen) and grows back into the full controls when you point at it, tab to it, pause, drag the seek bar or open a menu. Two seconds after you leave it, it shrinks again, and the controls then fade as before. The export chip and toasts move with it.
- Motion: the bar, toasts and the clip drawer now move in and out instead of popping. Settings → Advanced → Motion style (preview) switches between Quick (short, smooth, Windows-like) and Springy (a light bounce), so you can compare them; with Windows animations turned off everything is instant.
- The control bar's buttons are a little bigger, with slightly larger icons and crisper corners, and the full controls are calmer: Open and Speed on the left, back 5 s, Play and forward 5 s in the middle, and Mute, a ⋯ menu and Full screen on the right. The ⋯ menu holds frame back and forward, Loop and Always on top (their keys still work).
- Fixed: the app closed straight away on launch, because the Video panel's zoom slider reported a change while it was still loading.
- Copy frame (Ctrl+C) puts the current picture on the clipboard and Save frame (Ctrl+Shift+S) saves it to the snapshot folder from Settings → Video (Pictures\Aether when none is set), both with captions and without the on-screen display. A toast confirms, Save frame offers Show in folder, and a failure shows an amber toast. Both are in the right-click menu and can be changed in Settings → Shortcuts; Ctrl+C still copies text in a text box.

Each column lists the file's tracks as language · title · channels (5.1, 2.0), with SDH or Forced on subtitles, the current one checked and long names trimmed with the full name on hover. Subtitles have Off and Add subtitle file…, and both columns have a delay control that moves by 0.1 s.

Every panel now moves the same way: the clip list, Settings and its sections, Diagnostics and the Open URL box fade and slide in and out instead of popping, button highlights fade, and the Springy motion style also gives buttons a small squash when pressed.

### Fixed
- Skipping with the arrow keys or buttons is smoother (a held key no longer floods the player), the network cache setting is now respected, 59.94 and 119.88 Hz displays are paced exactly, and restarting the engine no longer causes a brief video stall.
- Rotating the video from the Video panel no longer squeezes the picture into a narrow strip with black bands; the picture now fills its window area at the rotated shape.
- Changing hardware decoding, audio passthrough or custom mpv options now applies with Restart engine straight away, without relaunching the app; the video carries on where it was.
- A video opened at launch (command line, Open with, Play with Aether) opens again and shows its picture instead of playing sound only.
- Fixed Settings content layout squishing and extra dead space by ensuring content column expands up to max-width without false centering.
- Fixed volume slider hit-testing blocked by "Mute (M)" tooltip when hovering over the volume button.
- Fixed software decoding (`hwdec=no`) frame pacing by disabling video latency hacks on CPU decode and boosting render loop thread priority.
- Restored "Report an issue" link on the About settings page.
